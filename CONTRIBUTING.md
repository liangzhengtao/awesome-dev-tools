# Contributing to Awesome Dev Tools

Thank you for your interest in contributing! This document provides guidelines and instructions for contributing.

**English** | [中文](#中文版)

## How to Contribute

### Reporting Bugs

If you find a bug, please open an issue with:

- A clear description of the problem
- Steps to reproduce
- Expected vs actual behavior
- Screenshots if applicable

### Suggesting New Tools

We love new tool suggestions! Please:

1. Check if the tool is already listed
2. Open an issue using the [Tool Request template](.github/ISSUE_TEMPLATE/request_tool.md)
3. Include:
   - Tool name and link
   - What it does
   - Why it's awesome
   - How it compares to alternatives

### Improving Documentation

- Fix typos or grammar errors
- Add missing information
- Update outdated links
- Improve code examples

### Adding a New Tool File

1. Fork the repository
2. Create a new branch: `git checkout -b add-new-tool`
3. Add your tool file following the template structure:
   - Overview
   - Comparison Table
   - Quick Start
   - Configuration
   - Tips
4. Update the README.md tools table
5. Submit a pull request

## Pull Request Process

1. **Fork** the repository
2. **Create** your feature branch (`git checkout -b feature/amazing-tool`)
3. **Commit** your changes (`git commit -m 'Add amazing tool'`)
4. **Push** to the branch (`git push origin feature/amazing-tool`)
5. **Open** a Pull Request

### PR Guidelines

- Use clear, descriptive commit messages
- Include screenshots for visual changes
- Update documentation as needed
- Keep changes focused and atomic
- Follow the existing code style

## Style Guide

### Markdown

- Use ATX-style headers (`#`, `##`, `###`)
- Use `-` for unordered lists
- Use `1.` for ordered lists
- Use fenced code blocks with language identifiers
- Keep lines under 120 characters when possible

### Tool File Structure

```markdown
# Tool Name

> Brief description

## Overview

Paragraph describing the tool.

## Comparison Table

| Feature | Tool A | Tool B |
|---------|--------|--------|

## Quick Start

### Installation and basic usage

## Configuration

### Recommended settings

## Tips

1. Tip one
2. Tip two

## See Also

- [Related Tool](./related-tool.md)
```

## Code of Conduct

Please read our [Code of Conduct](CODE_OF_CONDUCT.md) before contributing.

## Questions?

If you have questions, feel free to open an issue or reach out to the maintainers.

# 中文版

感谢你有兴趣贡献！本文档提供了贡献的指南和说明。

## 如何贡献

### 报告 Bug

如果发现 Bug，请提交 issue，包含：

- 清晰的问题描述
- 重现步骤
- 期望 vs 实际行为
- 如适用，附上截图

### 推荐新工具

我们欢迎新工具推荐！请：

1. 检查工具是否已被收录
2. 使用[工具推荐模板](.github/ISSUE_TEMPLATE/request_tool.md)提交 issue
3. 包含：
   - 工具名称和链接
   - 功能介绍
   - 为什么推荐
   - 与同类工具的对比

### 改进文档

- 修复拼写或语法错误
- 补充缺失信息
- 更新过期链接
- 改进代码示例

## Pull Request 流程

1. **Fork** 仓库
2. **创建** 功能分支 (`git checkout -b feature/amazing-tool`)
3. **提交** 更改 (`git commit -m 'Add amazing tool'`)
4. **推送** 到分支 (`git push origin feature/amazing-tool`)
5. **提交** Pull Request

### PR 规范

- 使用清晰的提交信息
- 视觉更改附上截图
- 同步更新文档
- 保持更改聚焦
- 遵循现有代码风格

## 行为准则

请在贡献前阅读我们的[行为准则](CODE_OF_CONDUCT.md)。

## 有问题？

如果有问题，请提交 issue 或联系维护者。
